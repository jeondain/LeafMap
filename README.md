# 🌱 풀잎맵 
> 전컴X소웨 연합 공모전 

재학생들이 학교 생활에 필요한 모든 정보를 한곳에서 얻을 수 있는 학교 생활 가이드 서비스입니다.  
학과 선택부터 지름길, 시설 이용, 맛집까지 선배들의 경험과 AI의 도움으로 정보를 쉽고 빠르게 찾을 수 있습니다.

## 주요 기능

### 🎓 학과 탐색 및 추천
**학과 선택 꿀팁**  
학과별 핵심 키워드, 이수 체계도, 졸업 후 진로 정보 제공
댓글을 통한 선배들의 조언 공유
  
**전공 적성 검사 기반 학과 추천**  
간단한 적성 검사 기반 개인 맞춤 학과 추천

### ✏ 게시판
**캠퍼스 생활 정보**  
숨겨진 지름길, 시설 이용 팁 등 학교생활 전반의 정보 공유 (운영자 인증 후 게시)   
일정 추천수 이상 시 풀잎 배지 부여

**근처 맛집 정보**  
맛집 리뷰 자유 작성 및 공유
풀잎 배지 받은 검증된 맛집은 홈 화면에 별도 노출 

### 🤖 풀잎 AI
커뮤니티 게시글 기반 AI 챗봇  
예시: "정릉 맛집 추천해줘 풀잎 배지 있는 게시글로만 부탁해!"

## 기술 스택

**Backend**
- Spring Boot, JPA, MySQL
- JWT, Spring Security

**Frontend**
- Swift (iOS)

**Infrastructure**
- AWS (EC2, RDS, S3), Docker
- Github Actions (CI/CD)

**AI**
- OpenAI GPT API

## 프로젝트 특징

🎯 **사용자 생성 콘텐츠 중심**  
재학생들이 직접 경험한 정보를 공유하는 커뮤니티 기반 플랫폼

🏆 **풀잎 배지 시스템**  
추천수와 운영자 채택을 통한 신뢰도 검증 및 참여 동기 부여

🤖 **AI 통합**  
커뮤니티 게시글 기반 AI 실시간 질의응답 제공

💬 **활발한 소통**  
댓글, 대댓글, 추천하기를 통한 선후배 간 정보 교류
